# 易创开发启动指南

本文档说明如何在本地启动和关闭「易创」的开发环境，包括桌面版（Tauri）与 Web 版（纯浏览器）两种形态。

## 环境要求

| 工具 | 版本要求 | 说明 |
|---|---|---|
| Node.js | ≥ 20（建议 22+） | 前端构建 |
| pnpm | ≥ 9（建议 10+） | 包管理，项目使用 pnpm workspace |
| Rust toolchain | ≥ 1.89 | 仅桌面版需要（`rustup` 安装） |

安装依赖（首次或拉取新代码后执行一次）：

```bash
pnpm install
```

> pnpm v10 会拦截依赖的安装脚本，项目已在 `pnpm-workspace.yaml` 中放行必需项（`esbuild`、`@parcel/watcher`、`vue-demi`），其余警告可忽略。

## 桌面版（主形态，功能完整）

### 启动

```bash
pnpm dev:desktop
```

- 自动依次执行：启动 Vite 开发服务器（端口 **4414**）→ 编译 Rust → 打开「易创开发版」应用窗口。
- **首次启动**需要全量编译 Rust 依赖，约 20～30 分钟（视机器性能），属正常现象。
- 之后每次启动为增量编译，通常只需几秒到十几秒。
- 代码变更热更新：前端改动即时生效；Rust 代码（`src-tauri/`）改动会自动重新编译并重启应用。

### 关闭

三选一：

1. **直接关闭应用窗口**（推荐）：`tauri dev` 检测到窗口退出后会自动结束并一并停止 Vite；
2. 在运行它的终端按 `Ctrl + C`；
3. 找不到终端时，Windows 下强制结束进程：

```powershell
taskkill /IM ew-client-desktop.exe /F
```

## Web 版（降级形态，便于快速调试前端）

### 启动

```bash
pnpm dev
```

- 启动 Vite 开发服务器（端口 **6789**），终端显示 `Local: http://localhost:6789/` 即成功。
- 浏览器访问：<http://localhost:6789>

### 关闭

1. 在运行它的终端按 `Ctrl + C`；
2. 若在后台运行或终端丢失，Windows 下按端口找到进程再结束：

```powershell
netstat -ano | findstr :6789        # 最后一列即 PID
taskkill /PID <上一步的PID> /F
```

## 两个版本的差异

| 能力 | 桌面版 | Web 版 |
|---|---|---|
| 数据存储 | SQLite（`ew-writing.db`） | IndexedDB |
| AI 直连模型服务商 | ✅ 免跨域 | ⚠️ 受浏览器跨域限制 |
| 榜单爬虫、提示词文件读写、备份到磁盘 | ✅ | ❌ 会提示改用桌面版 |

写作、书架等基础功能两个版本都可用；涉及 Tauri 能力的功能请用桌面版。

## 注意事项

- **端口冲突**：两个 Vite 端口均加了 `--strictPort`，端口被占用时会直接报错退出，需先释放端口（6789 / 4414）。
- **数据隔离**：开发版与正式安装版数据完全隔离（应用 identifier 带 `.dev` 后缀、产品名「易创开发版」），可放心调试。
- **数据库文件锁**：桌面版内置单实例锁，不要同时开两个桌面实例，否则会争抢 SQLite 文件锁。

## 其他常用命令

| 命令 | 作用 |
|---|---|
| `pnpm build` | 前端生产构建（含 `vue-tsc` 类型检查） |
| `pnpm tauri build` | 打正式安装包（NSIS / DMG，含更新签名产物） |
| `pnpm check` | 类型检查 + ESLint + Vitest 一键检查 |
| `pnpm lint` / `pnpm lint:fix` | 代码风格检查 / 自动修复 |
| `pnpm test` | 运行单元测试 |
| `pnpm check:contrast` | 主题 WCAG 对比度自检 |
