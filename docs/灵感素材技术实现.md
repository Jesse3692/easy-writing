# 灵感素材：技术实现细节

> 整理日期：2026-09-29（基于当前代码梳理，供后续维护与其他模块借鉴）
> 功能入口：侧边栏「灵感素材」（`src/views/Inspiration/index.vue`）

## 0. 总览

灵感素材是三个模块里最轻的一个，**纯本机、无爬虫、无独立服务**：

```
localStorage 单键 JSON（ew-local-inspirations）          ← 数据层，110 行
        ▲
        ├── 灵感页（Inspiration/index.vue，1234 行）      ← 记录/搜索/编辑/热门标签/AI 每日推荐
        ├── 写作台灵感面板（Writing/InspirationPanel.vue）← 同一存储，AI 生成直接入库
        └── 首页快记卡片（Home/QuickNoteCard.vue）        ← 同一存储，300 字快记
              共用 mention 式标签输入组件 InspirationInput.vue（633 行）
```

沿革与榜单/拆书同款：替代旧服务端 `/writing/inspiration` 数据通道，
**数据形状保持与老服务端接口一致**（`Inspiration` / `InspirationInsights` 类型不变），
用户将来要改造该功能时只换通道、页面零改动。

---

## 1. 数据层（`storage/local-inspiration.ts`）

- **存储介质**：localStorage 单键 `ew-local-inspirations`，值为整个灵感数组 JSON。
  选 localStorage 而非 IndexedDB 是有意的——灵感是短文本（≤500 字），量级很小；
- **负 ID 规约**：本地实体 id 用负数自减（`nextLocalId` 取当前最小 id 再减一），
  与本地书库同规约，为将来与服务端数据合并留出正 id 空间；
- **数据形状**（`types/index.ts:124`）：`{ id, content, tag?, isPinned?, createTime?, updateTime? }`
  （`bookId/authorId/sortNo` 为老服务端遗留字段，本地未用）；时间格式 `YYYY-MM-DD HH:mm:ss`；
- **CRUD**：`listLocalInspirations({tag?, keyword?})` / `add` / `update` / `deleteInspirations`。
  keyword 对 content + tag 做大小写不敏感的包含匹配；新增条目 `unshift`（最新在前）；
  读写整体 try/catch，失败只 console.warn 不打断界面；
- **Insights**：`getLocalInspirationInsights()` 返回 `{ hotTags, dailySuggestion }`——
  hotTags 是全部灵感按 tag 计数排序的 **Top 8**；`dailySuggestion` 恒为空串
  （AI 能力在页面层现做，见第 5 节）。

---

## 2. 「#标签」体系（双轨设计）

标签同时存在于两个地方，这是本功能最核心的设计：

1. **结构化字段** `item.tag`：每条灵感至多一个标签，用于分类 Tab、热门统计、过滤；
2. **文本 token**：content 里保留 `#标签 ` 前缀（`mergeTagIntoContent`：content 不以
   `#tag`/`#tag ` 开头时拼上去），用于列表内高亮展示和人类可读性。

- **提取**（`extractTagAndContent`）：正则 `/(^|[\s\u00a0\n])#([^\s#]+)/` 抽出第一个
  `#词` 作为 tag，其余为正文——只抽取，不改写正文其余部分；
- **持久化**（`persistTag`）：tag 存库前仅 trim，不做字符集清洗；
- **标签字符集**（输入组件侧）：中文/字母/数字/下划线/连字符（`#[\u4e00-\u9fa5a-zA-Z0-9_-]+`）；
- **展示合并**：读列表时统一 `mergeTagIntoContent` 回填 `#tag` 前缀，
  保证「存库正文不带 token、展示恒带 token」的一致观感。

## 3. 标签输入组件（`components/InspirationInput.vue`）

一个 contenteditable 富文本编辑器，把 `#标签` 渲染成**不可编辑的 span**（`contentEditable="false"`），
对外只 emit 纯文本（`innerText`）。三处复用：灵感页草稿框、灵感页行内编辑、写作台灵感面板
（`variant: default | compact | plain`）。

关键交互实现：

- **mention 弹层**：光标处文本匹配 `/(^|[\s\u00a0\n])#([^\s#]*)$/` 即触发；
  候选 = 历史标签（`tagOptions`，按使用排序去重）按输入过滤；支持 ↑↓ 循环选择、
  Enter 确认（无候选时直接创建当前输入）、Escape 关闭；
- **光标定位**：弹层跟随光标，用 `Selection.getRangeAt(0).getBoundingClientRect()`；
  光标在空节点拿不到 rect 时插入 `\u200b` 零宽字符做**测量标记**再移除（兜底）；
- **空格转标签**：输入 `#xxx ` 后空格，自动把 `#xxx` 文本区间替换成不可编辑标签 span
  （`convertTagOnSpace`）——即 placeholder 说的「输入 #标签 空格生成标签」；
- **单标签约束**：编辑器里已存在 `.inspiration-tag` 时不再触发 mention（`hasExistingTag`）；
- **退格整删**：光标紧邻标签 span 前按 Backspace，一次性删除整个标签（不会删半个字）；
- **中文输入法**：`compositionstart/end` 期间跳过 input 处理，避免拼音过程误触发标签转换；
- **回车换行**：`document.execCommand('insertLineBreak')`（避免 contenteditable 默认 div 换行）；
- **弹层时序**：blur 后延迟 120ms 才隐藏弹层，让 mention 项的 `mousedown.prevent` 先拿到点击。

## 4. 页面层（`views/Inspiration/index.vue`）

- **保存**：`extractTagAndContent` 拆出 tag/正文 → 空正文拦截、500 字上限 → 入库 →
  刷新列表与 Insights；草稿框内容双向绑定经组件转纯文本；
- **行内编辑**：点条目进入编辑态（复用 InspirationInput），**600ms 防抖自动提交**
  （`scheduleEditCommit`）+ 失blur 强制提交（`commitEdit(true)`）；空内容/超长时只在
  强制关闭时回滚原值并提示；内容与 tag 均未变则不写库；编辑期间强制切回「全部」Tab
  （防止编辑中条目被过滤掉消失）；
- **搜索**：`watch(keyword)` + 300ms 防抖走 `listLocalInspirations({keyword})`；
- **分类 Tab**：「全部 + 按 tag 聚合 + 未标签（`__untagged__` 哨兵值）」，带计数；
- **展开/收起**：`nextTick` 后逐条比较 `scrollHeight > clientHeight + 1` 判断溢出，
  溢出才显示「展开」按钮；
- **列表渲染**：`v-html` 前先 `escapeHtml` 完整转义，再只对第一个 `#tag` token 包高亮
  span（`renderListContent`）——**先转义再标注，无 XSS 注入面**（模板处有 eslint-disable 注释说明）；
- **右侧面板**：热门素材 = hotTags（空态文案「多记录几条灵感即可生成」，点击标签回填草稿）；
  每日推荐卡片带刷新按钮，空态显示「推荐灵感待接入本地 AI」；
- **其他**：复制到剪贴板、删除（本地过滤 + 清理展开/溢出/编辑三套状态）。

## 5. AI 灵感激发（每日推荐 / 写作台共用）

- **调用链**：`buildInspirationSparkMessages`（`config/ai-prompts.ts:149`）→
  `requestLocalChatCompletion({ scene: 'inspiration_spark' })` → 用户自己配置的文本模型；
- **素材**：最近 8 条灵感的**标签去重列表 + 内容前 60 字切片**——让 AI 顺着用户最近的思路出主意；
- **提示词**在本地提示词库 `inspiration` 槽位（`config/prompts/defaults-writing.ts:375`，用户可改）：
  > system：你是网文写作台的灵感助手。只输出灵感内容本身——一句话，不解释、不编号、不加引号。
  > task：给一条新的网文写作灵感：一句话，60 字以内，具体到能直接展开写（一个冲突、一个设定点子或一个画面），不要空泛的口号。

- **灵感页「每日推荐」**：AI 结果只进 `dailySuggestion` 卡片，用户点「+采纳」才填入草稿框
  （不直接入库）；刷新按钮可反复生成；未配模型时提示去模型管理；
- **写作台灵感面板**（`Writing/InspirationPanel.vue:313`）：同 scene 同素材，但 AI 结果
  **直接入库**并打 `AI灵感` 标签；还支持「新增空灵感」后聚焦输入；
- **首页快记卡片**（`Home/QuickNoteCard.vue`）：同一存储，300 字上限，失焦保存，
  空内容新增则回滚——灵感页/写作台/首页三处数据实时一致（同键读写）。

---

## 6. 备份与恢复

一键备份 zip（桌面端）里的 `local-storage.json` 收**全部 `ew-*` 前缀键**
（`storage/full-backup.ts` 的 `snapshotLocalStorage` 按 `LOCAL_STORAGE_PREFIX` 过滤），
`ew-local-inspirations` 自动包含，无需单独登记；恢复走 overwrite/merge 两模式。

## 7. 值得记取的设计点（供其他模块借鉴）

1. **双轨标签**：结构化字段（供统计/过滤/Tab）+ 文本 token（供展示/人类可读），
   入库时拆、展示时合——短文本场景下比纯结构化多对多标签表省一个存储层，比纯文本好过滤。
2. **mention 输入组件通用化**：`variant` 三形态、`options` 外部注入、emit 纯文本，
   任何「正文里嵌 #标签/引用」的输入场景都能直接复用。
3. **轻量数据用 localStorage 单键**：与 IndexedDB 库（榜单/拆书）按数据量级选型，
   备份体系按 `ew-` 前缀统一兜底，新键零登记成本。
4. **负 ID 本地实体规约**：全应用统一，未来接服务端正 id 合并互不冲突。
5. **AI 结果不直接落库**：灵感页的生成结果先展示、用户采纳才用——与写作台「直接入库」
   形成两种闭环样本，按场景选择。
6. **v-html 纪律**：先完整转义再做标记替换，并在模板处留 eslint-disable 注释说明无注入面。
